# Portfolio Kamilatus Syifaur Rohmah

## Cara membuka di Visual Studio Code

1. Extract file ZIP ini.
2. Buka Visual Studio Code.
3. Pilih **File → Open Folder**.
4. Pilih folder `portfolio_kamilatus`.
5. Pastikan file berikut terlihat:
   - `index.html`
   - `style.css`
   - `script.js`
   - `foto.jpeg`
6. Install extension **Live Server** jika belum ada.
7. Klik kanan `index.html`.
8. Pilih **Open with Live Server**.
9. Website akan terbuka otomatis di browser.

## Mengubah isi website

Semua teks utama ada di `index.html`.
Warna, layout, font, dan tampilan ada di `style.css`.
Animasi/menu mobile ada di `script.js`.

Foto yang digunakan adalah `foto.jpeg`. Jika ingin mengganti foto,
beri nama foto baru menjadi `foto.jpeg` lalu replace file lama.

## Catatan
Website ini dibuat dengan HTML, CSS, dan JavaScript sederhana sehingga mudah
dipahami dan diedit di VS Code.
